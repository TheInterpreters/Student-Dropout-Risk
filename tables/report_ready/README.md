# Report-ready aggregate tables

These files are generated by `python scripts/build_report_assets.py`. They consolidate the locked
final-test, W1 validation-audit and completed human-study results without rerunning model inference.

Use `project_numbers.json` for headline counts and metrics. Use the CSV files for formatted report
tables. Values remain subject to the scope notes in that JSON file and the limitations documented
in `README.md`, `W1_analysis/03_Full_Audit/Reports/W1_COMPLETE_REPORT.md`, and
`docs/HUMAN_STUDY_RESULTS.md`.
