# Report-ready figures

These aggregate figures are generated by `python scripts/build_report_assets.py`. They contain no
participant identifiers or free text. The human-study-only diagnostic figures are in
`figures/human_study/`.

The exception is `workflow_diagram.png`, the research-workflow diagram (Figure 1 of the final
report). It is drawn with TikZ from `workflow_diagram.tex`. To rebuild it, run this in this folder:

```
pdflatex workflow_diagram.tex
pdftoppm -r 250 -png -singlefile workflow_diagram.pdf workflow_diagram
```
